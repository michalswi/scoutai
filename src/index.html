Temperature Guidance

  • 0.0–0.3: Best for code analysis, security audits, bug finding (deterministic)
  • 0.4–0.7: Good for documentation, explanations, suggestions (balanced)
  • 0.8–1.0: More exploratory and creative, higher variance

Tip: start at 0.7 for balanced answers, lower it when you need strict, repeatable output.

Ollama URL Configuration

How it works:

  • Default: http://localhost:11434 - Connects to Ollama running on your local machine
  • Remote: http://192.168.1.100:11434 - Connect to Ollama on another machine in your network
  • Custom port: If Ollama runs on a different port, change 11434 to your port
  • Note: URL resets to localhost on app restart (not saved)

Quick tips:

  • Press Enter or click 🔄 Refresh to update connection
  • Status will show "Ready" when connected, or error message if failed
  • Make sure Ollama is running on the target machine

How Local Ollama Works

What it does:

Starts the local Ollama server (ollama serve) so chat requests go to http://localhost:11434.

Pulling models:

If a model is missing, you have two options:

  • Use ollama pull <model> in terminal, or
  • Click the 📥 Pull button in 'session [model] configuration' → Model section → 💡info (only available when Ollama is running locally)
  • Hit the 🔄 refresh models button after pulling to update the list

Environment Variables:

Use the ⚙️ Environment Variables panel to pass custom settings to ollama serve. Enable a variable by ticking its checkbox before starting Ollama.

Variable Default Description
OLLAMA_NUM_PARALLEL 5 Number of parallel requests processed simultaneously.
OLLAMA_CONTEXT_LENGTH 32768 Context window size (tokens). Larger values use more VRAM.
OLLAMA_KEEP_ALIVE -1 How long a model stays loaded after last request (-1 = forever, 0 = unload immediately, e.g. 5m).
OLLAMA_KV_CACHE_TYPE f16 KV cache quantization type. f16 for full precision; q8_0 reduces VRAM usage with minimal quality loss.
OLLAMA_FLASH_ATTENTION 1 Enables Flash Attention for faster inference and lower memory usage (1 = on, 0 = off).

Tip:

Leave this off if you already run Ollama elsewhere and just point the URL in 'Ollama Controls' → Ollama URL to that host.

Button Guide

📤

Send

Send your message to the AI model. You can also press Enter in the input field.

🎯

Focus

Toggle Focus Mode - hides all controls and shows only the chat and input. Perfect for distraction-free conversations.

📐

Fit

Reset the chat window to its default size. Useful after manually resizing the chat area.

💾

Save

Save the current session's chat history to a JSON file on your computer.

📂

Load

Load a previously saved chat history from a JSON file into the current session.

🆕

NewS

Create a new session tab. Each session has its own chat history and model configuration.

🗑️

Clear Chat

Clear all messages in the current session. This action cannot be undone.
